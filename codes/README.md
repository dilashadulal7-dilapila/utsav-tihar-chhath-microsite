
# Jhilimili – Where Light Meets Life

A festive interactive microsite celebrating the traditions, culture, and beauty of Tihar and Chhath.

## About the Project

Jhilimili is a web-based festive experience designed to showcase the spirit of Tihar and Chhath through interactive elements, cultural storytelling, and creative activities.

## Features

- Tihar and Chhath festival sections
- Interactive diya experience
- Rangoli creation activity
- Festival wish card
- Interactive festive elements
- Responsive website design

## Technologies Used

- HTML5
- CSS3
- JavaScript
